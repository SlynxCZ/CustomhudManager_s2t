# One line per release: append what changed and the CI cuts the next tag.
First release: IToolkitHud004 -- text slots, interaction prompt, toasts, announcement, countdown, big timer, status chips, corner card, progress bar, hit feedback, event feed, overlays, and HudMenu on the HUD through the core's menu system (a dead player gets the cursor). Needs source2toolkit v1.0.34; the players need the s2t_hud / s2t_menu layouts from panorama/ in an addon.
The version the plugin reports is the release tag and the commit (SEMVER @ GITHUB_SHA from the build), no metadata file; file headers under the Source2Toolkit license.
Rebuilt against the SDK whose hook header survives windows.h coming first (MSVC).
Windows: the plugin links the static CRT the SDK library is built with.
The interface is this repository's own header, public/ICustomhudManager.h (ICustomhudManager, CUSTOMHUD_MANAGER_INTERFACE_VERSION = ICustomhudManager001); the SDK no longer carries it. Plugins vendor public/ and declare g_pCustomhudManager themselves.
ICustomhudManager002: ShowReveal (a card in the upper middle with an entrance: tag, title, line, info, captioned block) and ShowStats (a label/value panel at the bottom left with a bar and a two-number footer, sending only what changed); HudColor::Gold. Needs the funplayhud addon with the new panels.
ICustomhudManager004: the objective tracker, HudOverlay::Blood, HudMenu::Grid tiles and a second line on menu options; the card in the top right corner; the fade animations play (unquoted animation names, no more missing-animation console spam); curtime clock. Built against the handler-owned toolkit API: needs source2toolkit v1.0.35 and the funplayhud addon with the new layouts.
Rebuilt against plugin API 3 (IToolkitCommands003): needs source2toolkit v1.0.37, which refuses the earlier builds.
Author string is a u8 literal and MSVC builds with /utf-8, so the name is UTF-8 on every compiler.
Rebuild against SteamDatabase/Protobufs with its per-game descriptor.proto (bd8f82d); no code changes.
Rebuilt against the Source2Toolkit SDK on alliedmodders/s2sdk (protobufs from s2sdk's own protos, steam_api linked by the SDK); no code changes.
